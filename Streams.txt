Interface --when ever we add methods in interface , it will effect the below mentioned Implemented class.

So Java 8 introduced a default methods and Static methods

Default methods are called using Object Reference

interface A
{
    default void show() {
        System.out.println("Default shows");
    }
}
interface B
{
    default void show() {
        System.out.println("Default show");
    }
}
class C implements A,B
{
    //@Override
    public void show()
    {
        System.out.println("Show from class C");
    }
    public void callsAinterface()
    {
        A.super.show();
    }
    public void callsBinterface()
    {
        B.super.show();
    }

}
class Main {
    public static void main(String[] args) {
C c=new C();

c.callsAinterface();
    }
}
If 2 interfaces have the same default method,
the implementing class MUST override that method.


Static methods We called using Interface name.

InterfaceName.methodName()

Why Static methods In Interface:

 Static methods in Java 8 are used to ready made methos  and common methods in interfaces without affecting existing implementations.
No need to write same logic again and again
Static methods are belongs to Classes
in java 8 static methods belongs to Interface.

Without object creation we can call static methods using interface name.


1. So we have default methods then why static method ?

-> In default methods can be overriden.
-> but Static methods cant be overriden.

//Method Reference:
===========

Method Reference is a shortcut of lambda expression to call an existing method directly.

When to use method reference
👉 Use it when:

You are only calling an existing method
You are not adding any new logic

 Step 1: Normal way (Lambda)

list.forEach(x -> System.out.println(x));
You are saying:

take x
print x
Step 2: Think carefully 🤔
👉 Are we writing new logic here?
❌ No
👉 We are just calling:

list.forEach(System.out::println);

👉 Lambda = cooking from scratch 🍳
👉 Method reference = using ready-made food 🍱

import java.util.*;

class Main {
    public static void main(String[] args) {

        String s = null;

        } else {
            System.out.println("String is null");
        }
    }

=======
Streams
=======
 Streams are used to process data from collections (like List, Set) in a simple and efficient way.
-> Used to process the data
-> Collections are used store the data.
-> Source of the data for Streams can be Array or Collections.
-> Streams will not change the original data structure of the source (it will just process the data)
==================
Stream Operations:
==================

Intermediate Operations : It will perform operations on the stream and returns a new stream
Ex: Filter  map
Terminal Operations : It will take input and will provide result as output.

============
Filter method :
=============

Filtering means getting required data from Original data.

Filter method will take input as predicate and return output as Stream Boolean.


EX: List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5);

nums.stream()
    .filter(n -> n % 2 == 0)   // keep even numbers
    .forEach(System.out::println);

==================
Mapping Operations
==================

mapping operations are used to transformtions(Conversion) the stream elements and returns transformed elements as new straem.

EX:

List<String> names = Arrays.asList("ram", "shyam");

names.stream()
     .map(String::toUpperCase)
     .forEach(System.out::println);

//or//


names.stream()
     .map(S->S.toUppercase())
     .forEach(System.out::println);

filter() → select data ✅
map() → change data ✅


=======
MapInt
=======
Map returns a Stream<R> (object stream).
mapToInt returns an IntStream (primitive stream)
Use mapToInt if the end result is int-based numeric processing.


Map -->executes-->Takes an object--->Returns another object(object-> Object)
mapInt-->returns ---> Takes an object-->convert to Primitive INT.[Used when you want int values (not Integer objects)}

👉 map() converts elements to objects, while mapToInt() converts elements to primitive int for efficient numeric operations. 👍


List<String> words = Arrays.asList("alpha", "beta", "gamma");

int totalLength = words.stream()
    .mapToInt(name->name.length())
    .sum();  // IntStream.sum()

System.out.println(totalLength); // 14

Collectors
=============
Collectors are used to collect data from Streams:[Collectors take data from a stream and convert it into list, set, map, or other formats]

 toList / toSet / toCollection

1.  toList():

	 Convert stream to List
				.collect(Collectors.toList()


2.toSet
	Convert stream to Set

				.collect(Collectors.toSet())


import java.util.*;
import java.util.stream.Collectors;

public class StreamToSetBasic {
    public static void main(String[] args) {
        List<String> names = Arrays.asList(
            "Alice", "Bob", "Charlie", "Alice", "bob", "Diana", "Bob", "Eve", null
        );

        // Remove duplicates; HashSet has no predictable order; null allowed
        Set<String> set = names.stream()
                .collect(Collectors.toSet());

        System.out.println("Set (toSet)   : " + set);
    }
}
